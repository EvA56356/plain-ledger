# 协作服务器与客户端

此分支基于绿色 main UI，不依赖其他 UI 分支。它是可本地运行的协作实现，真实短信、域名、HTTPS、备份及持续运维尚需部署者配置。没有把任何个人账单上传到公网。

## 本机启动

Python 3.9+，仅标准库：

```powershell
python cloud_server.py --port 8766 --dev-sms
```

打开 http://127.0.0.1:8766/ 。开发模式不发送短信，会在验证码响应及页面显示测试码。请使用虚构测试号码；不要将该模式通过代理暴露到公网。服务始终绑定回环地址。数据库 `cloud.sqlite3` 和同目录 `cloud.secret` 自动生成，均禁止提交。服务器未运行时，页面显示连接错误与重试提示。

Android 协作版包名 `cn.plainledger.shared`，与原离线版独立安装。首次打开输入自己的服务器地址。公网服务器必须 HTTPS；HTTP 仅允许 `127.0.0.1` / `localhost`。模拟器本机联调可使用：

```powershell
adb reverse tcp:8766 tcp:8766
```

然后在协作版填写 `http://127.0.0.1:8766`。手机真机使用自己的 HTTPS 地址。Android 中会话 Cookie 保存于应用私有偏好，不暴露给 JavaScript；当前未额外做密钥库加密。

## 账号与共享

- 手机号验证码注册、密码登录、昵称修改、修改密码、验证码重置密码、退出登录。
- 密码 12—128 字符，以随机盐 scrypt 存储；验证码 HMAC 摘要保存，5 分钟有效，最多 5 次尝试。发送与登录有单进程限流。
- 修改或重置密码后，其他设备会话失效。会话有效期 7 天。
- 个人空间可管理多个个人账本；“账号与共享 → 新建共享账本”创建单个空白共享账本空间，原个人历史不会自动复制或共享。切换顶部空间下拉即可访问。
- 创建者按手机号邀请已注册用户；对方在账号菜单接受或拒绝。邀请 7 天有效，可撤回。支持可编辑、只读；创建者可移除成员，不能移除自己。
- 每个共享空间仅一个账本；需创建另一个空间来增加共享账本。空间中分类、账户和预算由成员共享，不跨空间混用。
- 打开或回到客户端时自动读取服务器最新数据；刷新按钮显示同步中、成功时间、超时、登录失效和权限错误。正在编辑时不会刷新覆盖表单。
- 保存采用版本号比较。冲突返回 409，保留待保存副本，可下载后再决定放弃并刷新，禁止静默覆盖。待保存副本目前仅在内存中，关闭页面会丢失，请立即下载。没有离线写入队列；网络失败后不会声称保存成功。
- 网页使用 HttpOnly、SameSite=Strict Cookie；请求包含来源和自定义头校验。Android 使用本地原生网络桥接，仅允许固定 API 路径，不加载远端脚本到原生桥。
- 财务数据和账号保存在部署者服务器 SQLite 中，未额外加密。服务器管理者可访问数据，真实使用前应评估部署方的可信程度。

## 正式短信与 HTTPS

不传 `--dev-sms`，配置以下环境变量（仅在服务器本机，不提交）：

```text
TWILIO_ACCOUNT_SID=<服务商账号>
TWILIO_AUTH_TOKEN=<服务商密钥>
TWILIO_FROM=<可用发送号码>
LEDGER_PUBLIC_URL=https://ledger.example.com
```

当前适配 Twilio，需自行确认目标地区的号码与短信发送支持，并承担服务商费用。未配置时接口返回“短信服务尚未配置”，不会伪装成发送成功。验证码接口可能触发真实短信费用，勿对未完成限额、风控和监控的公网服务开放。

用 Caddy / Nginx 等 HTTPS 反向代理转发到 `127.0.0.1:8766`，必须保持单一外部来源与 `LEDGER_PUBLIC_URL` 一致。设置 HTTPS 后 Cookie 带 Secure；开发验证码与公网 URL 不可同时启用。此版本使用单进程锁和进程内限流，不适合直接多进程扩容；不要通过放宽 CORS 或启用明文公网连接解决配置问题。

## 备份、测试与范围

备份运行中的 SQLite 应使用 SQLite backup API，或停服后备份数据库及密钥；备份包含敏感资料，请限制访问。`cloud.secret` 用于验证码摘要，丢失会使尚未使用的验证码失效。当前没有账号删除、账本所有权转移、短信二次验证登录、离线冲突自动合并或运维控制台。

```powershell
python test-cloud.py
node test-reports.cjs
node test-accounting.cjs
node test-calendar.cjs
python test-storage.py
```

集成测试使用临时数据库和虚构号码，验证注册、验证码重放、重置密码、会话撤销、邀请接受、成员隔离、只读权限、撤销访问、版本冲突、非法数据和跨站请求拒绝。真实短信服务未配置或实测，公网部署未执行。
