# 协作版数据范围

协作版 Android 包名 `cn.plainledger.shared`，有 INTERNET 权限。默认绿色离线版没有此权限，两者数据库互相独立。

协作版注册手机号、昵称、密码摘要、会话摘要、账本数据、成员关系和邀请记录保存在你配置的服务器。密码使用随机盐 scrypt，验证码使用 HMAC 摘要；生产短信的手机号和短信内容会发送给部署者配置的短信服务商。开发短信模式不会真实发送。

共享成员可以读取共享空间内的全部账单、分类、账户、预算和备注。邀请方需选择可编辑或只读，对方接受后才获得权限。用户需自行避免在共享备注中记录不应共享的个人信息。个人历史账单不会自动复制到共享空间。

服务器数据库没有额外加密。服务管理者和拥有数据库文件访问权限的人可能访问这些数据。网页会话使用 HttpOnly Cookie，Android 会话保存在应用私有偏好中。应用中失败保存的副本保留在内存，可导出；离开页面可能丢失。

自动记账识别在手机本机执行，页面全文不上传；用户确认保存的账单字段按本分支同步到配置的服务器。

禁止上传 `.sqlite3`、数据库附属文件、`.secret`、`.env`、会话 Cookie、服务商密钥、签名密钥、真实手机号、真实账单、导出备份及运行日志到公开 GitHub。本仓库仅发布源码、文档与虚构测试代码。
