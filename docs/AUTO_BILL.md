# 离线自动记账

Android 设置页进入“离线自动记账”，阅读说明后点击开启，并在系统无障碍设置中手动启用“简账 · 离线自动记账”。默认关闭，可在简账中暂停，或在系统中关闭服务。

当前仅监听支付宝和微信的窗口变化，读取界面公开的无障碍文字。不截图、不联网、不点击付款，不保存完整页面内容或密码控件内容。识别到“支付成功 / 付款成功”和唯一金额后显示提示，点击“核对并记账”打开编辑表单；金额、账户、分类、日期和当前账本仍需核对，点击保存才写入 SQLite。

本地临时草稿仅包含金额、支付来源和识别时间，在读取后清除，超过五分钟不再使用。未使用的草稿可能保留到下一次读取或卸载；不进入 JSON/CSV 备份。当前账本和功能开关保存在应用私有偏好中。页面文本仅在服务内存中短暂处理，不写入日志或上传。

限制：不识别转账、退款、失败、待支付或多金额页面。同一来源、同一金额在 90 秒内只提示一次，连续同额付款可能漏记。提示 20 秒后消失，可手动补记。没有 OCR 后备路径；支付软件版本、语言、页面结构及系统后台限制可能影响识别。打开历史支付成功页也可能触发提示，因此必须核对。未做真实支付宝/微信付款端到端验证，不保证所有版本可用。

电脑预览不具备跨应用读取能力。当前无障碍能力面向用户自行安装测试，商店分发需要另行审查相应平台要求。
