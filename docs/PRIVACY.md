# 隐私与仓库内容说明

本分支是可选联网协作版，请同时阅读 [协作版数据范围](PRIVACY_SHARED.md)。用户配置并启用协作后，确认保存的账单会同步至配置的服务器；待核对草稿与识别原文留在本机。公开仓库仅保存通用应用源码、测试代码、构建脚本、文档以及使用模拟数据的界面截图。

## 不提交的内容

- SQLite 数据库及 WAL、SHM 等附属文件。
- 真实账单、账户余额、JSON 备份、CSV/TSV 导出。
- Android 签名密钥、证书私钥、环境变量文件和访问令牌。
- 本机配置、绝对个人目录、设备标识及运行日志。
- 原始第三方 APK、逆向工作目录和下载的开发工具。
- 生成的 APK 与构建缓存。

`.gitignore` 用于防止常见误提交，不代表能自动识别所有敏感信息。上传前应检查 `git diff --cached` 和 `git ls-files`。已经被 Git 跟踪的文件不会因新增忽略规则自动移除。

## 应用运行

### 无感自动记账

用户同意并开启后，仅处理支付宝、微信、美团和美团外卖。其他应用只观察窗口与包名身份，不读取页面文字或截图。优先使用无障碍文字；文字不可读或出现付款线索时，才在当前前台窗口进行有时限的本机 OCR 补扫。识别出的聊天、登录、可见密码和认证页面跳过识别，禁止截图的窗口不会尝试绕过。文字不可读等情况下，这些应用的非付款页面仍可能短暂参与本机判断。

截图和页面原文只在内存中处理，不保存、不上传。待核对草稿保存金额、来源、识别渠道、时间、测试标记及草稿标识，保存或明确忽略前保留在本机。诊断与待核对通知不包含页面原文、截图或商户信息；通知也不展示金额。用户仍需核对并确认保存才会写入账本。可随时在设置中暂停识别或撤销系统授权。

### 本机预览与导出

本机预览服务只绑定回环地址，并校验 Host 和 Origin。备份导出使用应用私有缓存以支持文件选择期间的进程重建；导出完成或取消后清除。导出失败或中断时，缓存可能保留至重试、重新导出或系统回收，不进入公开源码或安装包。

Android 协作版声明 INTERNET 权限；资源、本机记账逻辑及中文 OCR 模型仍随应用打包。协作连接使用 HTTPS，HTTP 仅允许本机回环地址，具体数据范围见上述协作版说明。未启用协作时仍使用本机账本。

导出的备份包含完整记账信息，请自行妥善保管，避免上传到公开仓库。当前没有额外的数据库加密或应用锁。源码公开不等于个人账单公开。
