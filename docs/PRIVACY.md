# 隐私与仓库内容说明

本项目面向离线记账。公开仓库仅保存通用应用源码、测试代码、构建脚本、文档以及使用模拟数据的界面截图。

## 不提交的内容

- SQLite 数据库及 WAL、SHM 等附属文件。
- 真实账单、账户余额、JSON 备份、CSV/TSV 导出。
- Android 签名密钥、证书私钥、环境变量文件和访问令牌。
- 本机配置、绝对个人目录、设备标识及运行日志。
- 原始第三方 APK、逆向工作目录和下载的开发工具。
- 生成的 APK 与构建缓存。

`.gitignore` 用于防止常见误提交，不代表能自动识别所有敏感信息。上传前应检查 `git diff --cached` 和 `git ls-files`。已经被 Git 跟踪的文件不会因新增忽略规则自动移除。

## 应用运行

Android 不声明 INTERNET 权限；资源和记账逻辑均随应用本地打包。电脑版只使用本机回环 HTTP 服务连接本机 SQLite，不包含云同步或远程分析服务。

导出的备份包含完整记账信息，请自行妥善保管，避免上传到公开仓库。当前没有额外的数据库加密或应用锁。源码公开不等于个人账单公开。
